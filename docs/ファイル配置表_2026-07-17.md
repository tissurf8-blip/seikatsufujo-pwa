## 3. 実行方法

### A. Fable に依頼する（一括整理）

新規ダウンロードが 20 件以上溜まったら Fable に頼む:

```
プロンプト例:
「Desktop と Downloads を配置表に従って整理して。
配置表: ~/Desktop/claud/ファイル配置表_2026-07-17.md
削除は絶対しない、移動 or 保留のみ。」
```

### B. 手動で少数ファイルを振り分け

Finder で D&D。分類判定は上のフローチャート参照。

### C. Chrome MCP + bash（Claude 経由）

少数ファイルなら Claude に依頼 → bash mv で移動。**注意**: サンドボックスは cross-mount 移動不可（copy+unlink になり unlink 失敗）、**同一 mount 内 rename のみ通る**。

---

## 4. 制約・注意点

### サンドボックスの制約（2026-07 発見）
- `bash rm` は Downloads・Desktop で "Operation not permitted"
- **同一 mount 内の rename は通る**（`~/Downloads/A → ~/Downloads/整理/A` OK）
- **クロスマウントは copy 可・元 unlink 不可**（`~/Downloads → ~/Desktop/claud` はコピー後、元ファイルが残る）
- 削除が必要な場合は **Finder で手動 Cmd+Delete**

### 個人ファイル
- 親父さんフォルダは**絶対に触らない**
- 家族写真・確定申告・契約書・パスワード関連は**移動もせず報告のみ**
- 個人スクショは `_個人_写真スクショ_YYYY-MM-DD/` に集約してけんし判断

### 判断保留の扱い
- 迷ったら `_未分類_YYYY-MM-DD/` フォルダに集約
- 削除は絶対にしない
- けんしの判断待ちリストとしてレポート
