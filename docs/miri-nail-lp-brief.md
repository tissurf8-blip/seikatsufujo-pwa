## 1. 商品（実物確認済み）

ネイルチップ10本セット。ラウンド〜ショートオーバル、ショート〜ミディアム丈。

**ハロウィン濃度：4本 / 10本**

| | 本数 | 内容 |
|---|---|---|
| ハロウィン | **4本** | 白の立体ぷっくりおばけ（大）／同（小）／オレンジの立体かぼちゃ／**「B♡♡」レタリング**（Booのooがハート） |
| 秋ネイル | **6本** | ボルドーのラメ×ゴールドのハート＋パール／ベージュマーブル×ゴールドの立体リボン／チョコブラウンのキルティング×ゴールドスタッズ／ホワイト×ブラウンのマーブル×金箔／コーラルピンク×ゴールドのハート枠／ダークブラウンのラメ×ヌードのマットな立体リボン |

**カラー：**
- **紫＝ゼロ。オレンジ＝かぼちゃ1粒のみ。黒＝かぼちゃの線のみ。**

**立体パーツ8点以上、手描きマーブル3本、キルティング1本＝技術難度が高い。**

## 3. ポジション

> # 「10月のための、大人かわいい秋ネイル。よく見ると、ハロウィン。」

**秋ネイルが主、ハロウィンが従。** ハロウィンネイル需要は約3週間だが、秋ネイル需要は9〜11月。

## 4. 訴求の優先順位

| 順位 | 伝えること | 手段 |
|---|---|---|
| **1位** | 仮装しなくてもハロウィンを楽しめる（＋2026年は10/31が土曜） | FVの**コピー** |
| **2位** | いつものコーデになじむ、怖くない大人かわいいデザイン | FVの**画像**／第2ブロック |
| **3位** | 必要な日だけ・繰り返し使える | 第3〜4ブロック |
| **4位** | セルフでは無理な作り込み | **価格提示の直前** |
| 番外（必須） | サイズ・納期・交換保証 | 全ブロックの後 |

**FVは「言葉より先に画像で語る」。** 視覚の1位＝2位の内容、言語の1位＝1位の内容。
順位を入れ替えるのではなく、担当する感覚器官を分ける。

## 5. コピー（確定案）

```
【FVメイン】今年のハロウィンは、爪の先だけ。
            （代替：仮装しなくても、指先からハロウィン。）

【FVサブ】  10本のうち、4本だけハロウィン。
            コーラルピンクとベージュの、怖くない大人ハロウィンネイル。
            ハロウィンが終わっても、そのまま秋ネイルに。
```

**用途別**

| 場面 | コピー |
|---|---|
| Instagram広告（認知）A案 | **これ、ハロウィンネイルです。**（意外性型） |
| Instagram広告（認知）B案 | **10本のうち、4本だけハロウィン。**（事実提示型） |
| 広告（9月） | **10月31日は、土曜日です。** |
| 広告（10/1〜10/15限定） | **仮装できない日にも、ハロウィンはある。** |
| LP「怖くない」ブロック | **怖くないハロウィン、はじめました。**／**Boo の oo を、ハートにしました。** |
| LP中盤（安心づけ） | **気づかれないくらいが、ちょうどいい。** |
| LP後半（背中押し） | **ハロウィンが終わっても、秋は続く。**／**6本は、ただの大人かわいい秋ネイルです。** |
| 差別化の証明 | **使ったハロウィンカラーは、かぼちゃのオレンジだけ。** |

**A/Bテストは「これ、ハロウィンネイルです。」vs「10本のうち、4本だけハロウィン。」から。**
効き方の原理（意外性 vs 事実提示）が違うので、事前に予測できない。

### 絶対にメインコピーに置いてはいけない言葉

> **大人かわいい／ニュアンス／くすみ／普段使い／簡単／貼るだけ／上品／シンプル／サロン級**

競合が全部使い切っています。ショップ名にすら使われている（「大人ネイルチップ＊CHIARAnails」）。
**商品説明の中で補助的に使うのは可。主役にしないこと。**

### 使ってはいけない感情表現

「寂しい」「物足りない」「置いていかれる」は**本人が認めたくない感情**なので、
図星であるほど反発が起きます。**欠乏ではなく充足で語る。**

| ❌ | ⭕ |
|---|---|
| 仮装しないと寂しい | 仮装は、しない。でも、10月は少しだけ、楽しみたい |
| 何もしないのは物足りない | 今年は、爪の先だけ |
