### なぜそう言えるのか（根拠5点）

**根拠1：「仮装しない人」は例外ではなく、多数派である【事実】**
2025年調査で「仮装しない」が**全体の約8割**（[ファーストイノベーション](https://prtimes.jp/main/html/rd/p/000000391.000098210.html)）。
さらに決定的なのは、NEXER調査で**仮装で挑戦したいテイストの1位が「ワンポイント仮装」**だったこと（[NEXER](https://prtimes.jp/main/html/rd/p/000003234.000044800.html)）。
→ **「仮装しないけどハロウィンは楽しみたい」というMIRI NAILの仮説は、市場データで明確に裏付けられます。** しかも「ワンポイントで参加したい」という需要が"1位"として存在する。

**根拠2：2026年は「仮装しない人」に構造的な追い風がある年【事実】**
- **10月31日が土曜日**（2025年は金曜）。翌11月1日も日曜で、**週末2日間フルで使えるハロウィン**（[シェアフル](https://sharefull.com/content/entertainment/22229/)）
- **東京ディズニーリゾート「ディズニー・ハロウィーン」は2026年9月16日〜10月31日開催。ただし全身仮装OKは9/15〜9/30と10/16〜10/31のみで、10月1日〜10月15日は全身仮装対象外**（[トラベルWatch](https://travel.watch.impress.co.jp/docs/news/2096844.html) / [公式](https://www.tokyodisneyresort.jp/dream/event/costumes2026.html)）
- USJ「ハロウィーン・ホラーナイト」は2026年9月11日〜11月8日と**約2ヶ月間**（[USJ公式](https://www.usj.co.jp/web/ja/jp/events/halloween-extreme-autumn-2026/halloween-horror-nights/halloween-horror-nights-academy-15years-of-screams)）

→ **【推測】「イベント期間は約2ヶ月あるのに、全身仮装できるのは一部期間だけ」という構造は、"仮装以外の方法で季節感を出したい"需要を制度的に生み出しています。** これはLPで使える強力な文脈です。

**根拠3：ネイルチップは、縮小するネイルEC市場の中で数少ない成長カテゴリ【事実】**
2026年2〜4月のネイルEC市場は約22億円（前年比 **−5.4%**）と縮小する中、**ネイルチップは +6.7%、一方ジェルネイルは −7.9%**。同期間の**平均単価は +17%**（[Nint ECデータラボ](https://www.nint.jp/blog/ec-nail-care-market-review/)）。
→ **単価が上がっている市場＝「安さ」で戦う必要がない市場。** デザイン価値で売るべきという仮説は正しいです。

**根拠4：競合の「大人・淡色ハロウィン」は、言葉としては存在するが、商品としては薄い【事実＋推測】**
minne / Creemaのハロウィンネイルチップを実地調査した結果、**カテゴリの中心は「血のり・ホラー・グロ」「コスプレ・仮装連動」「パープル×オレンジ×ブラックのTHEハロウィン」「量産型・地雷系」**でした（詳細は③）。
一方、「大人・淡色」文脈の商品は確かに存在するものの（例：[moAni「大人ピンクのさりげないハロウィンネイル」](https://minne.com/items/11008399)、[「大人女子のオフィスでも楽しむハロウィンネイル」](https://minne.com/items/38129469)）、**数としてはごく少数**です。
→ **【推測】「大人かわいい淡色ハロウィンネイルチップ」は、ニーズはあるが供給が薄い、狙う価値のある空白地帯です。**

**根拠5：ターゲットが求めているのは「ハロウィン」ではなく「雰囲気」【事実】**
SHIBUYA109 lab.の around20 女性調査で、ハロウィン参加理由の1位は**「ハロウィンの雰囲気が好き」47.3%**、2位「イベントが好き」42.2%。SHIBUYA109館内調査では**「写真・動画映え」が49.4%**。同調査は **around20はホラーより「かわいい」ハロウィンを好む**と結論づけています（[SHIBUYA109](https://www.shibuya109.co.jp/news/1466/) / [PR TIMES](https://prtimes.jp/main/html/rd/p/000000014.000033586.html)）。
→ **顧客は「ハロウィンをやりたい」のではなく「ハロウィンっぽい雰囲気の中にいたい」。この差がコピーの精度を決めます。**

### 4-4. 結論：MIRI NAILの推奨価格と、その理由

> **推奨：3,280円〜3,980円（税込）。値引き・セール訴求はしない。**

**理由2：2,000円以下は「タグ羅列SEO勝負」の土俵だから【推測】**
1,200〜1,700円帯の商品名は「春 夏 秋 冬 イベント 遊び デート」のようなキーワード羅列型です。この土俵で勝つには**大量出品と検索順位競争**が必要で、世界観で選ばれるブランドの戦い方ではありません。

**理由3：「安さ」を言うと、商品の意味が壊れるから【推測】**
MIRI NAILの価値は「仮装しなくてもハロウィンを楽しめる」という**体験の代替**です。
- 全身仮装コスチュームは数千円〜1万円
- ネイルサロンでのハロウィンネイルは5,000〜10,000円前後【事実】

→ **3,000円台は「仮装するより安く、サロンより安く、しかも当日以外も使える」という比較対象を提示できる、最も説得力のある価格帯**です。
「サロンより安い」を**メイン訴求にはしない**が、**価格の納得材料としては使う**（LP後半）。

**理由4：価格を下げるほど、サイズ不安が致命傷になるから【推測】**
後述のとおりネイルチップ最大の障壁はサイズです。**3,000円台ならサイズオーダー対応・サイズ交換保証のコストを吸収できます**が、1,500円では吸収できません。**価格はサービス設計とセットで決めるべきです。**

| **リボン** | ◎ トレンド適合＆差別化 | 2025AW〜2026のガーリー系トレンド。**ハロウィン文脈でのリボンは競合が少ない**（量産型・地雷系での使用が中心） |
| **ハート** | △ 競合重複 | 量産型・地雷系で多用されており、**単体では差別化にならない**。他要素との組み合わせで意味を持たせる必要あり |
| **キルティング** | **◎ 最大の差別化ポイント** | トレンド要素でありながら、**ハロウィンネイルチップでの使用は競合で確認できず**。秋の「あたたかい素材感」を出す装置として機能 |

### 5-4. 飽和している表現 vs まだ空いている領域

**【飽和・避けるべき】**
- 血のり・血しぶき（グループAが完全に占拠）
- 紫×オレンジ×黒のジャックオーランタン（グループBが占拠）
- 魔女・黒猫・コウモリの記号的配置（サロン・チップ双方で定番化）
- 「コスプレ」「仮装」を商品名に入れる（客層がズレる）
- 蜘蛛の巣

**【まだ空いている】**
- **くすみピンク／ベージュ主体のハロウィン**（＝紫・オレンジを一切使わないハロウィン）
- **ぷっくり × おばけ × 淡色**の3点セット
- **キルティング × ハロウィン**
- **ボルドーを「血」ではなく「秋の大人色」として使う**
- **リボン × ハロウィン**（ガーリーだが量産型ではない上品な文脈で）

### 5-5. 【重要な警告】要素過多のリスク【推測】

ご提示のモチーフは **おばけ／かぼちゃ／リボン／ハート／キルティング** の5種類、カラーは **くすみピンク／ベージュ／ブラウン／ボルドー／ゴールド** の5系統です。

> **10本のチップに、5モチーフ×5カラーを全部載せると、「大人かわいい」ではなく「にぎやか」になります。**

競合の秋ネイル強豪（Rio GALLERY、remee nail）が支持されている理由は、**要素を絞って統一感を出しているから**だと考えられます。

**推奨する設計原則（画像確認後に再検証が必要）：**
- **主役モチーフは1つに絞る → 「ぷっくりおばけ」**（最大の差別化ポイントであり、最もかわいく、最も怖くない）
- かぼちゃ・リボン・ハート・キルティングは**「主役を引き立てる脇役」として、10本中2〜3本まで**
- ゴールドは**「点」で使う**（面で使うとブライダル・成人式に寄る）
- **無地／ワンカラーのチップを最低3本入れる**（＝「休符」がないと大人っぽく見えない）

**これはLPの写真構成にも直結します。** FVで見せるべきは「全部盛り」ではなく、**「一番大人かわいく見える角度」**です。

## ⑩ その人の購入前心理（認知 → 興味 → 比較 → 不安 → 購入）

### 【検証】「仮装はしないけど、何もしないのも寂しい」は有効か？

> **結論：有効。ただし"寂しい"という言葉をそのままLPに書くのは逆効果。**

**有効である根拠【事実】**
- 「仮装しない」8割 = 大多数が「何もしない側」にいる
- にもかかわらず「ワンポイント仮装」が挑戦したいテイスト1位 = **「何もしないのは嫌だ」という気持ちが実在する**
- 参加理由1位は「ハロウィンの雰囲気が好き」47.3% = **参加したい動機は"雰囲気"であり、仮装ではない**
- 20〜30代の51.6%がハロウィンに興味あり = **興味はあるのに8割が仮装しない＝ギャップが存在する**

→ **この4つのデータのギャップこそが、MIRI NAILの市場です。** 「興味はある（51.6%）」のに「仮装はしない（80%）」。**このギャップを埋める商品が、ワンポイント仮装（1位）です。**

**しかし「寂しい」と書いてはいけない理由【推測】**
「寂しい」は、**本人が認めたくない感情**です。LPで「あなたは寂しいですよね」と言われると、**図星であるほど反発が起きます**（＝「別に寂しくないし」）。

**正しい言い換え：**
| ❌ 書いてはいけない | ⭕ こう書く |
|---|---|
| 「仮装しないと寂しい」 | 「仮装は、しない。でも、10月は少しだけ、楽しみたい」 |
| 「何もしないのは物足りない」 | 「今年は、爪の先だけ」 |
| 「置いていかれる」 | 「わたしのペースの、ハロウィン」 |

**原則：欠乏（ないもの）ではなく、充足（あるもの）で語る。** 「〜がない」ではなく「〜がある」。

### 15-3. 差別化の3層構造

```

### 15-4. 差別化の一撃：「紫とオレンジを使わないハロウィン」

これで**弱点2（商品の核）と弱点3（当日だけ）が同時に解消**されます。
**メインコピー自体は変えなくても、この2段構えで実戦投入可能な水準になります。**

   → 「かわいい」→「あ、おばけ」→「仮装しなくても、か」の順で入る
```

**つまり：**
- **視覚の第1位＝2位の内容**（大人かわいい淡色デザインそのもの）
- **言語の第1位＝1位の内容**（仮装しなくてもハロウィンを楽しめる）

この2つを**同じFVの中で同時に成立させる**のが正解です。順位を入れ替えるのではなく、**担当する感覚器官を分ける**。

### 19-3. 修正点2：4位は「価格提示の直前」に置く

「細かいハロウィンアートが完成済み」は、**購入検討の初期には響きません**（まだ買う気がないから）。
これは**価格を見せた瞬間に「高い」と思わせないための材料**です。

```
LP の流れ：
  ... → 商品詳細 → ★4位「これ、セルフでは無理です」（制作過程・アップ写真）
      → 価格提示 → 「だから3,980円です」が納得される
```

### 19-4. 最終的な優先順位（確定版）

| 順位 | 伝えること | LP内の位置 | 手段 |
|---|---|---|---|
